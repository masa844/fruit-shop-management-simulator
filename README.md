# 7日間くだもの店経営シミュレーター

くだもの店の店長になり、7日間の営業で黒字を目指す経営シミュレーションゲームです。

りんご、みかん、バナナ、いちご、さくらんぼ、メロン、巨峰の仕入数と販売価格を決め、お客さんの買い物を見守りながら、売上と利益を増やしていきます。

## ゲームを遊ぶ

GitHub Pagesの公開ページへアクセスするだけで遊べます。

https://masa844.github.io/fruit-shop-management-simulator/

ダウンロードして遊ぶ場合は、ファイルを展開して `index.html` をブラウザで開いてください。インストールやログインは必要ありません。

## 遊び方

1. 元手10万円から、各商品の仕入数と販売価格を決めます。
2. 「開店する」を押すと、10時から18時まで営業します。
3. お客さんが来店し、予算や好み、商品の価格に応じて買い物をします。
4. 閉店後に、売上高、売上原価、商品廃棄損、売上総利益、固定費、営業利益を確認します。
5. 前日の結果を参考に、翌日の仕入数や販売価格を調整します。
6. 7日間の最終資金と経営成績を確認します。

営業終了時の手元資金が0円以下になると、営業を継続できずゲーム終了となります。

## このゲームで体験できること

* 仕入数量と在庫管理
* 販売価格と需要の関係
* 売上と利益の違い
* 売上原価、商品廃棄損、固定費
* 客単価と販売数量
* 日々の結果をもとにした経営改善

天候、近隣イベント、競合店の特売などによって、その日の来店客数や商品の売れやすさも変化します。

## 動作環境

一般的なパソコンやタブレットのWebブラウザで動作します。データの保存やユーザー登録には対応していない、1回完結型のゲームです。
