# 7日間くだもの店経営シミュレーター

HTML / CSS / JavaScriptだけで動く、授業用の簡易経営シミュレーターです。

## 起動方法

`index.html` をブラウザで開いてください。  
インストール、サーバー、データ保存、ログインは不要です。

## 主な内容

- 元手10万円
- 7種類の果物
- 仕入数と販売価格の設定
- 前日の仕入数と販売価格を翌日に引き継ぎ
- 10:00〜18:00のリアルタイム営業
- お客さんの来店・購入アニメーション
- 標準版より来客数を約20％増加
- 価格、需要、予算、嗜好による購買判定
- 家賃、光熱費、人件費
- 固定費は1日9,000円
- 売上、売上原価、粗利益、営業利益
- 売れ残りと廃棄原価
- 日ごとの商品別販売数と売れ残り数
- 7日間の最終評価

## ファイル

- `index.html`
- `style.css`
- `game.js`

## 難易度調整

- 初期値のままでは売れ残りにより小幅赤字になりやすい設定
- 商品別の販売数・売れ残りを見て、仕入数や価格を調整すると黒字化しやすい
- メロンとシャインマスカットの基礎需要を増加
- 贈答品客・高級品好きの客を追加
- 参考価格より安くすると販売確率が明確に上昇
- 雨や競合店イベントの来客減少を緩和

- 初期仕入数は全商品10個
- 安価な商品は売り切れやすく、高級果物は売れ残りやすい需要設定
